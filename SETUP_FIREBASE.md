# 🔥 Firebase Setup for Vercel Deployment

## Important: Generate firebase_options.dart

The app requires `lib/firebase_options.dart` to compile. This file is generated by FlutterFire CLI.

## Quick Setup

### Option 1: Generate Locally and Commit

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Login to Firebase
firebase login

# Generate firebase_options.dart
flutterfire configure
```

When prompted:
- Select your Firebase project (or create new)
- Select platforms: web, android, ios, windows, macos, linux

This will create `lib/firebase_options.dart` with your Firebase configuration.

**Then commit it:**
```bash
git add lib/firebase_options.dart
git commit -m "Add Firebase configuration"
git push
```

### Option 2: Use Environment Variables (Advanced)

If you prefer not to commit `firebase_options.dart`, you can:
1. Use environment variables
2. Generate it during Vercel build (requires Firebase CLI in build)

## For Vercel Deployment

**Recommended:** Generate `firebase_options.dart` locally and commit it to the repository.

The file contains your Firebase project configuration and is needed for the app to compile.
