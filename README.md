# Parakeet 🦜

**The Airbnb for Pet Rentals** - A marketplace connecting pet owners with people seeking temporary pet companionship.

## 🎯 Vision

Parakeet is a two-sided marketplace platform that enables:
- **Pet Owners (Hosts)**: List their pets for short-term rental/companionship services
- **Pet Renters (Guests)**: Browse, search, and book pets for temporary companionship experiences

Similar to how Airbnb connects property owners with travelers, Parakeet creates a trusted platform for pet rental experiences.

## 🚀 Features

### Current (MVP Phase)
- ✅ User authentication (Login/Register)
- ✅ Pet listing creation with comprehensive profiles
- ✅ Firebase integration (Auth, Firestore, Storage)
- ✅ Multi-platform support (Web, iOS, Android, Desktop)

### In Development
- 🔄 Pet browsing and search
- 🔄 Booking system
- 🔄 Payment processing
- 🔄 Messaging system
- 🔄 Reviews and ratings

## 📱 Tech Stack

- **Framework**: Flutter (Dart)
- **Backend**: Firebase (Auth, Firestore, Storage)
- **Platforms**: Web, iOS, Android, Linux, macOS, Windows

## 🛠️ Getting Started

### Prerequisites
- Flutter SDK (3.6.1+)
- Firebase project configured
- `firebase_options.dart` file (generated via FlutterFire CLI)

### Installation

1. Clone the repository
```bash
git clone [repository-url]
cd parakeet
```

2. Install dependencies
```bash
flutter pub get
```

3. Configure Firebase
```bash
flutterfire configure
```

4. Run the app
```bash
flutter run
```
